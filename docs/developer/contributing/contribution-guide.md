# Contribution Guide

The root [contribution guide](../../../CONTRIBUTING.md) defines the current
submission and verification requirements.

## Contribution license

prik is distributed under the MIT License. Contributions are accepted under
the same MIT terms. By submitting a contribution, a contributor agrees to
license it under those terms and represents that they have the right to do so.
Contributors whose work is owned by an employer or another organization must
obtain authorization before submitting it.

## Change workflow

Start by identifying the public behavior and its owning stage. Update the
relevant documentation before implementation, then change the implementation
and focused tests together. The [development workflow](../development-workflow.md)
maps common changes to their required evidence, and the
[pull request workflow](pull-request-workflow.md) covers submission and review.
